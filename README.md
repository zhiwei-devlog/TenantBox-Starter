# 📦 TenantBox-Starter

> 开箱即用的多租户 Java 后端底座。整合 Redis、线程池、租户级 RBAC 与定时任务。不是 SDK，是一个拿来就能写业务的起步包。

## ✨ 核心特性 (Features)
- 🏢 **多租户架构**：支持租户级数据隔离（物理/逻辑隔离）。
- 🛡️ **租户级 RBAC**：细粒度的用户、角色、权限管理。
- ⚡ **Redis 整合**：开箱即用的缓存、分布式锁及 Session 管理配置。
- 🧵 **线程池管理**：预置配置，支持动态参数调整与监控。
- ⏱️ **定时任务**：集成动态定时任务管理，支持分布式调度。
- 🛠️ **各种工具类**：封装常用的工具，减少重复造轮子。

## 🛠️ 技术栈 (Tech Stack)
- **后端**: Java 17 / Spring Boot 3.x
- **数据库**: MySQL / PostgreSQL
- **缓存**: Redis
- **ORM**: MyBatis-Plus / Spring Data JPA
- **构建工具**: Maven / Gradle
